台彩同步助手

在桌面 Chrome 正常開啟台彩後，回決策中心按一次同步。不需要付費資料 API、匯出 HAR 或在本機執行指令。平台不會自動下注。

下載與安裝（只需一次）

  1. 下載同步助手 v1.0.0（ZIP），解壓縮取得 NBA-Twsport-Sync 資料夾。請保留這個資料夾；安裝後移動或刪除它，助手會無法使用。
  2. 在 Chrome 網址列輸入 chrome://extensions，開啟右上角「開發人員模式」。
  3. 按「載入未封裝項目」，選擇解壓縮後的 NBA-Twsport-Sync 資料夾（不是 ZIP）。
  4. 確認助手識別碼為 kijmgoejmindnnhhkbpognmpciahnana。權限僅限台彩官方的兩個網域：www.sportslottery.com.tw 與 www-talo-ssb-pr.sportslottery.com.tw。
  5. 回到本平台，登入並重新整理決策中心，確認不再顯示「請使用已安裝同步助手的桌面 Chrome」。

這是本專案提供的本機套件，尚未上架 Chrome 線上應用程式商店。請自行審閱並載入；助手只接受本平台決策中心的要求，不需要台彩帳號密碼或 API key。

每次同步

  1. 用同一個 Chrome 使用者設定檔正常開啟台彩 NBA 盤口，保持分頁開啟。
  2. 在決策中心選今日或明日，按「同步台彩盤口」，保持頁面開啟直到顯示結果。
  3. 查看實際擷取時間、匯入結果與更新後的決策。沒有正 EV 或有效額度時，成功同步仍可能沒有可操作機會。

無法同步時

  • 助手未連線：確認使用相同的 Chrome 設定檔，助手已啟用，然後重新整理決策中心。
  • Python 處理器未連線：稍後重新整理；持續出現時請檢查系統狀態。
  • 台彩阻擋、要求降低頻率或資料格式改變：助手會停止，不繞過防護；不要連續重按。HAR 保留作備援。
  • 更新助手：下載新版並解壓縮到原資料夾，在擴充功能頁按助手的「重新載入」，再重新整理決策中心。

手機未提供此流程。助手只傳送盤口必要欄位，不讀取或上傳 cookie、登入密碼、帳戶與下注紀錄。免費瀏覽不代表可轉載，盤口介面須登入才能查看。
