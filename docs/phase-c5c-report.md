## 3. Early-season prior strategy

`core/models/temporal_model.py`：每個 walk-forward fold 只用該 fold 的訓練賽季擬合。對指標 m、本季已賽 n 場：

```
current-only : est = L + w·(x̄ − L)                         w = n / (n + k)
blend        : est = L + w·(x̄ − L) + (1 − w)·ρ(c)·(P − L)   ρ(c) = a + b·c
```

L = 上季聯盟平均、x̄ = 本季平均、P = 上季同 franchise 平均、c = 名單延續性（ret_min_pct；本季第一場前未知 → 用訓練集季初平均 c̄≈0.77）。k 用格點、a/b 用最小平方，目標是「該隊下一場的實際值」（等價於常態-常態經驗貝氏；k = 單場雜訊變異 / 隊伍間實力變異）。**沒有寫死任何權重**；隨 n 增加 w → 1，上季影響自動下降（有測試）。

擬合結果（est_net_rtg）：

| fold（評測季） | current-only k | blend k | ρ(0.5) | ρ(0.75) | ρ(0.95) |
|---|---|---|---|---|---|
| 2023-24（驗證） | 12 | 20 | 0.33 | 0.45 | 0.54 |
| 2024-25 | 10 | 15 | 0.38 | 0.59 | 0.76 |
| 2025-26 | 8 | 12 | 0.34 | 0.61 | 0.82 |

三個 fold 的 b 都 > 0：**名單越延續，上季資訊越可信**；第 n 場時本季權重 = n/(n+k)，例如 k=12 時第 12 場本季 50%。

**策略比較**（預測下一場 est_net_rtg 的 MSE，依本季場次分桶；參數只用該季之前資料擬合）：

| 策略 | 2023-24 1–5 / 6–10 / 21+ | 2024-25 1–5 / 6–10 / 21+ | 2025-26 1–5 / 6–10 / 21+ |
|---|---|---|---|
| 聯盟平均 | 216.6 / 178.5 / 272.6 | 197.2 / 193.6 / 279.9 | 222.0 / 269.2 / 290.1 |
| 只用上季 | 213.6 / 172.7 / 264.2 | 179.6 / 186.6 / 272.1 | 216.2 / 233.9 / 291.1 |
| 本季原始平均 | 278.0 / 182.4 / 249.9 | 254.0 / 192.8 / 255.5 | 272.5 / 246.7 / 264.3 |
| 固定 70% 上季 / 30% 本季 | 217.3 / 167.2 / 255.9 | 180.4 / 179.4 / 261.6 | 214.3 / 228.0 / 277.2 |
| 收縮（只用本季） | 216.9 / 170.2 / 250.0 | 188.4 / 178.9 / 254.5 | 215.2 / 242.3 / 262.9 |
| 收縮 + 上季（固定 ρ） | 212.2 / 167.9 / 250.1 | 176.5 / 176.3 / 254.2 | 207.7 / 230.8 / 263.3 |
| **收縮 + 上季 ρ(延續性)** | 211.9 / **166.8** / 250.1 | **175.6** / 176.1 / 254.1 | 211.1 / **229.7** / 263.2 |

- 季初 1–10 場：加入上季先驗**三季都比只用本季好**（1–5 場 MSE −2.3% / −6.8% / −1.9%）；季中以後兩者相同（w→1）。
- 「固定 70/30」季初尚可，但季中以後明顯較差（21+：255.9 vs 250.1、277.2 vs 263.2）——**驗證不支持固定權重**。
- ρ(延續性) vs 固定 ρ：差異很小（一季 30 隊，延續性的訊號量有限），方向不一致。
- 單場雜訊極大（MSE ~250 ≈ 單場 net rating 標準差 16），所以這些改善在最終模型層會被稀釋（§10、§11）。

## 4. Roster continuity definition

本季**已打過**的比賽 + 上季同 franchise 的球員分鐘（`player_game_stats`，只有實際上場者）：

| 欄位 | 定義 |
|---|---|
| `ret_min_pct` | 本季至今總分鐘中，上季也替本隊上場的球員所占比例 |
| `ret_starter_min_pct` | 本季先發分鐘中，上季也替本隊上場者所占比例 |
| `prev_min_returning_pct` | 上季本隊分鐘中，本季已替本隊上場者所占比例（季初會低估受傷尚未出賽者） |
| `starter_continuity` | 本季預期先發（本季最近 10 場先發次數前 5）中，上季也是本隊預期先發的比例 |
| `rotation_continuity` | 本季分鐘前 8 名 ∩ 上季分鐘前 8 名 / 8 |
| `roster_prior_pm48` | 本季上場球員（本季分鐘加權）**上季**的收縮正負值 /48 分鐘：Σ share·48·pm/(min+500)。名單版的上季先驗——交易來的球員帶著自己的上季表現。 |

- **本季第一場之前一律 NaN**（沒有可靠的開季名單歷史資料；`players.team_id` 是現況，用它會洩漏）。模型以 `cont_known` 指示 + c̄ 處理，不補造。
- 上季先驗**不會**因 franchise ID 相同就給相同權重：ρ(c) 隨延續性變化，`roster_prior_pm48` 直接追蹤球員。
- 分布（每隊本季第 10 場前）：ret_min_pct 平均 0.74–0.76（範圍 0.28–0.99）、starter_continuity 0.53–0.65。延續性低的一半球隊，季初 10 場 net rating 與上季的差距平均 4.99，高的一半 4.09（相關 −0.11，n=120 隊季）：**方向符合預期但訊號弱**。
- `roster_prior_pm48` 只用上季正負值（賽前已知），**不用於傷病的球員重要性**（§6 只用分鐘/先發）。
- **教練延續性**：沒有可靠資料，列為 future work，未補造。

## 5. Injury probability calibration

`InjuryCalibrator`（temporal_features.py）：P(absent | status, 報告距開賽 <3h / ≥3h)。**嚴格 walk-forward**：一場比賽結束、併入狀態後，才把「賽前狀態 vs 是否上場」計入；某場的特徵只用更早結束的比賽。兩層 Beta 收縮（狀態層向 C.5B 常數收縮 10 個虛擬樣本、狀態×時距層向狀態層收縮 20 個）。母體 = 近 10 次出賽平均 ≥ 12 分鐘的角色球員（列名者 + 本隊最近 5 場有上場但未被列名者 = Not Listed）。是否上場只用於「之後」的比賽，從不作為當場特徵。

各決策時點的實際缺陣率（五季合計；early = ET 賽事日 00:00 前最後一份報告，T-60 / T-15 = 開賽前 60 / 15 分鐘）：

| 狀態 | 固定先驗 | early（n / 缺陣率） | T-60 | T-15 |
|---|---|---|---|---|
| Out | 1.00 | 20,294 / 99.4% | 30,592 / 99.99% | 33,600 / 99.99% |
| **Doubtful** | **0.75** | 1,019 / **93.2%** | 695 / **98.1%** | 36 / 97.2% |
| Questionable | 0.50 | 7,422 / 44.4% | 5,472 / 41.7% | 366 / 36.1% |
| Probable | 0.15 | 2,610 / 9.4% | 1,999 / 4.8% | 128 / 5.5% |
| Available | 0（v1 視同 0） | 823 / 7.9% | 4,857 / 6.7% | 9,810 / 5.2% |
| Not Listed | 0 | 93,460 / 8.6% | 114,210 / 7.3% | 113,912 / 7.0% |

- **Doubtful 先驗 0.75 明顯偏低**：實際 93–98%。walk-forward 估計在 2022-23 開季就到 0.94（T-60），2025-26 開季 0.975。
- Probable 先驗 0.15 偏高（實際 5–9%）；Not Listed / Available 的角色球員仍有 5–9% 不上場（休息、臨時傷病、DNP-CD），不是 0。
- **報告時效（time-to-tipoff）**：同一決策時點內，報告距開賽幾乎都落在同一區間（T-60：99.9% 為 1–3 小時；early：全部 ≥ 12 小時），所以時距分桶在單一時點內沒有足夠變異可估。跨時點比較則清楚：**越早的報告越不可靠**（Doubtful 93% vs 98%、Probable 9.4% vs 4.8%）。因此 production 應依實際決策時點使用對應的校準表。
- 在評測賽季觀測上，缺陣預測的 Brier：walk-forward **0.0566** vs 固定常數 0.0607（T-60）；early 0.0738 vs 0.0794；T-15 0.0480 vs 0.0515。
- **對模型的實際影響很小**：E@T-60 校準 vs 固定常數 log loss −0.0004（CI [−0.0010, +0.0002]，2025-26 單季顯著、2024-25 不顯著）。原因：被影響最大的 Doubtful 很少（每季 ~140 人次），Questionable 0.42 vs 0.5 差距小。結論：校準是「正確的做法」，但不是改善的主要來源。

## 6. Minutes-weighted player availability

球員重要性**只由賽前的上場分鐘 / 先發 / 輪替使用量估計**（有測試：改變當場分鐘不影響當場傷病特徵）。P(absent) 用 §5 的校準值。

| 欄位 | 定義 |
|---|---|
| `inj_min_lost_role` | Σ P(absent) × 球員自身最近 10 次出賽平均分鐘（相對滿編） |
| `inj_min_lost_recent` | Σ P(absent) × 球員在本隊**本季最近 10 場**的平均分鐘（DNP 記 0）——相對近期常態；長期缺陣者近期分鐘 ≈ 0，不與近期戰績重複計算 |
| `inj_exp_starters_avail` | 預期先發 5 人的 Σ(1 − P(absent)) |
| `inj_rotation_avail_pct` | 近期分鐘前 8 名的期望可出賽分鐘比例 |
| `inj_top3_absent_w` | 近期分鐘前 3 名的 Σ P(absent) |

**核心 vs 邊緣球員**（E vs E_count；E_count = D + 只有「Out 人數」）：

| | 勝負 log loss | 分差 MAE |
|---|---|---|
| E_count（人數） | 0.5977 | 11.116 |
| E（分鐘加權） | **0.5922** | **10.978** |
| E − E_count（合併，95% CI） | −0.0055 [−0.0095, −0.0017] | −0.137 [−0.204, −0.077] |
| 2024-25 / 2025-26 | −0.0035（不顯著）/ −0.0075 | −0.115 / −0.159（皆顯著） |

分鐘加權明顯優於人數。勝負 E 模型（≤2024-25 訓練）標準化係數最大的是 `inj_min_lost_role_diff`（−0.19，大於 `elo_diff` +0.16）；`inj_min_lost_recent_diff` 係數接近 0（與 role 版高度共線，模型選了 role 版）。總分類目標上傷病沒有可測得的貢獻（§9）。

## 6.5 Modeling protocol

- **時間切分**：嚴禁隨機切分。驗證 fold：train ≤ 2022-23 → 2023-24。評測 fold：2024-25 用 ≤ 2023-24 訓練、2025-26 用 ≤ 2024-25 訓練（expanding window）。
- **所有選擇只在驗證 fold**：C（邏輯迴歸）/ alpha（Ridge）格點、訓練起始賽季（2021-22 或 2022-23）、XGBoost 三組設定、每個 target 用哪個特徵組（預先寫死的規則：驗證 primary metric 最小者）。評測賽季只跑一次（凍結設定）。收縮參數（k、ρ）屬於模型擬合，每個 fold 用該 fold 訓練賽季重擬合。
- 特徵組在看結果之前就固定（不做逐步特徵選擇）：

| 組 | 勝負 / 分差 / 上半場分差 | 總分 / 上半場總分 |
|---|---|---|
| A | elo_diff | Phase C `total_est`（雙方近 10 場攻守平均） |
| B | Phase C 5 特徵（elo_diff、b2b_diff、margin10_diff、rest_diff、form10_diff） | total_est、h1_total_est、休息/背靠背、季後賽 |
| C | B + 本季收縮 net/分差/上半場、l10/l5、趨勢、四因子、本季 H2H | B + 本季期望得分、節奏×效率、l10 節奏、得分趨勢、上季聯盟得分 |
| D | C（本季收縮 → 上季先驗混合）+ 延續性、名單先驗 | 同左 |
| E | D + 分鐘加權傷病 | 同左 |
| E_count | D + Out 人數 | 同左 |
| E_lean | Elo + 本季/先驗 + 傷病精簡版（不含 Phase C 跨季 form/margin10） | 精簡版 |

- Primary metric：勝負 log loss（再看 Brier、校準）；回歸 MAE。Accuracy 為次要。顯著性：比賽日（ET）區塊 bootstrap 2,000 次的成對差異 95% CI。

| 增量 | 勝負 log loss | 分差 MAE | 總分 MAE | 上半場分差 MAE | 上半場總分 MAE |
|---|---|---|---|---|---|
| A（Elo 重擬合）− Elo 原始 | −0.0123 ✔ | 0.000 | −0.001 | 0.000 | −0.026 ✔ |
| B − Phase C | 0（相同模型） | −0.161 ✔（Ridge 勝 XGB） | −0.085 | −0.043 | −0.088 ✔ |
| **C − B（本季 / 近況）** | −0.0004 | −0.014 | **−0.239 ✔✔** | −0.028 | **−0.151 ✔✔** |
| **D − C（上季先驗 / 延續性）** | −0.0022 ✔（單季皆不顯著） | −0.028 | +0.001 | −0.002 | +0.001 |
| **E − D（傷病 / 可用性）** | **−0.0098 ✔**（2025-26 ✔✔，2024-25 CI 上界 +0.0001） | **−0.211 ✔✔** | −0.002 | −0.030（兩季方向相反） | −0.014 |
| E − E_count（分鐘加權 vs 人數） | −0.0055 ✔ | −0.137 ✔✔ | +0.002 | −0.017 | −0.014 |
| E_lean − E | +0.0028 | +0.071 ✔（較差） | −0.048 | +0.027 | −0.036 |

✔ = 合併 95% CI 不含 0；✔✔ = 兩個評測賽季各自也不含 0。

解讀：
- **勝負 / 分差的改善幾乎全來自傷病與可用性**。本季近況（C）對勝負沒有增量——Phase C 的 Elo + 近 10 場分差已涵蓋大部分「目前實力」。
- **總分類的改善來自本季節奏 / 得失分**（C），傷病與先驗都沒有增量。
- **上季先驗 / 延續性（D）**：勝負合併有小幅顯著改善（−0.0022），但兩季單獨都不顯著，回歸目標沒有。屬「tiny but consistent in sign」的等級。
- 精簡版 E_lean 並沒有比較好（分差顯著較差），所以保留 Phase C 的特徵 + 新特徵、靠 L2 正則化，比手工刪減好。
- Phase C 的 XGBoost 回歸本身就輸給 5 特徵 Ridge（B）——複雜模型在這個資料量下沒有優勢。

## 13. Limitations

1. **只有一個驗證賽季**（2023-24，1,313 場）做選擇；總分類「E_count vs D vs E」的選擇在雜訊範圍內。
2. 評測 2,631 場；季初分桶每季只有 ~75–155 場，CI 很寬。
3. pace / ORtg / DRtg 是 box-score 估計（box-v1），stats.nba.com 仍被擋，未與官方 advanced 對照。
4. Elo baseline 用 elo-v1.0 已寫入的預測（含休息調整；當時 `injuries` 幾乎是空的，所以沒有傷病調整）。
5. **本季第一場前不知道名單**（沒有歷史開季名單資料）；延續性與名單先驗從第 2 場才有。2021-22 沒有上季資料。
6. `roster_prior_pm48` 使用上季正負值（賽前已知、但雜訊大，以 500 分鐘收縮，常數未調參）；兩個評測季在季初分桶上方向不一致。
7. 傷病報告歷史只回填開賽前 0–2 小時整點 + 前一日 17:00 + 當日 10:00（C.5B §8.9），所以「時距」分桶在單一時點內幾乎沒有變異；early 時點只是 production 排程的近似。
8. Not Listed / Available 的缺陣（5–9%）包含休息、DNP-CD 與交易邊界情況，未細分。
9. 教練延續性、旅行距離、球員層級 on/off 都沒有可靠資料 → future work。
10. E 模型各季 calibration slope 0.88 / 1.08，需上線後監控。
11. 附加賽（30 場）不在評測集合（與 Phase C 一致），但會進入特徵狀態。
12. `inj_min_lost_role` 與 `inj_min_lost_recent` 共線；模型主要用 role 版（相對滿編），長期缺陣者的影響部分已被近期戰績反映（C.5B §8.4）——L2 正則化處理，沒有手動刪除。

## 14. Recommended production model / 是否可進入 Phase C.5D

**建議（全部由驗證賽季決定，評測只用來報告預期表現）：**

| Target | 模型 | 特徵組 | 超參數 | 訓練資料 |
|---|---|---|---|---|
| 勝負 | 邏輯迴歸（StandardScaler） | E（25 個 diff 特徵） | C = 0.01 | 2021-22 起全部 |
| 分差 | Ridge | E | alpha = 1000 | 同上 |
| 總分 | Ridge | E_count（≈ D；傷病無貢獻） | alpha = 1 | 同上 |
| 上半場分差 | Ridge | E_count | alpha = 1000 | 同上 |
| 上半場總分 | Ridge | E_count | alpha = 1 | 同上 |

- 特徵：pregame-v2；收縮/先驗參數（k、ρ(c)、e）每次重訓時用全部已完成賽季重擬合。
- 傷病：walk-forward 校準器在 production 持續累積（以實際決策時點的報告校準）；決策時點建議 **每日台灣中午出 early 版（顯示用）+ 開賽前約 60 分鐘重算**（T-15 無額外增益）。
- **不使用 XGBoost**（驗證全數落敗）。
- 季初前 10 場的預測應在前端標示「樣本少」（模型層季初改善未被證實）。

**可以進入 Phase C.5D**，C.5D 需要處理：
1. Production inference：對未開賽比賽建立 v2 特徵（狀態 = 所有已結束比賽；傷病 = 最新報告；校準器狀態持久化），產生 `predictions`（新 `model_version`）與 `features_json.contributions`（邏輯迴歸可用精確 log-odds 貢獻）。
2. 2026-27 開季：第一場前延續性未知 → 使用 c̄；可評估用官方開季名單（cdn/stats roster，**只在開季當下抓取**）補足第一場的延續性——歷史回測無法驗證此項，需另行標註。
3. 定期重訓 / 收縮參數重擬合流程與 artifact 版本化。
4. 監控：上線後每週的 log loss / Brier / calibration slope、傷病校準表漂移。
