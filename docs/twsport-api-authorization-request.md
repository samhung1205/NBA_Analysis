主旨：詢問 NBA 台灣運彩賽前盤 API：個人分析用途授權與最新資料規格

您好：

我正在維護個人、非商業的 NBA 分析工具，希望使用貴方台灣運彩資料 API，取代手動擷取盤口。用途包含賽前機率與賠率比較、本人手動投注決策及紀錄，不會透過平台自動下注、不代操，也不轉售資料。

預計使用方式是：本人在網站按「更新台彩盤口」後，由雲端 Python 程式呼叫 API，將必要的賽事／盤口快照保存至資料庫，再計算分析結果。網站部署於 Cloudflare Pages、Python 位於 Railway、資料庫位於 Supabase；希望在登入保護下供本人使用。

想請您協助確認下列授權與規格，再決定是否申請付費 API：

1. **用途與資料權利**：上述個人分析與投注輔助用途是否包含於授權？是否允許在上述雲端主機處理、保存原始盤口快照及衍生分析？歷史快照可保留多久，訂閱結束後能否保留既有分析及稽核紀錄？貴方是否有權授予本用途所需的資料使用權？請提供適用的 API 授權條款；若需來源標示或禁止公開展示，也請告知。
2. **最新及未來賽事**：API 是否目前仍提供「今天及明天、尚未開賽」的 NBA 最新台彩盤口？文件的日期範圍寫過去 30／180 天，請確認是否也能查詢已開盤的未來賽事。`mode=close` 在未開賽時是否代表最新報價，賽後是否只是已封存尾盤？`date` 依哪個時區、哪個日期規則選場？
3. **時間與新鮮度**：`time`、`odds[].update` 的時區為何？`update` 是價格變更時間、來源最後確認時間，還是供應商擷取時間？有沒有獨立的「最後成功向台彩確認」時間、資料延遲或服務心跳？價格一直沒變時，要如何證明仍是有效報價？文件寫每 10–20 分鐘更新，目前的延遲與維運保證為何？
4. **玩法與結算**：能否提供全場獨贏／讓分／大小，以及上半場獨贏（三向主／和／客）／讓分／大小？全場各玩法是否包含延長賽？整數盤 push 如何結算？讓分線是否一律為主隊顯示線？如果只有部分玩法，也請列明。
5. **能否單場投注**：範例的 `s`「串關數」具體意義為何？如何辨識允許單場投注、至少二串一及不可投注的盤口？有沒有單場資格、停售／暫停／封盤、改期或取消狀態？主盤 `m` 改變及多條線同時存在時，如何判讀？
6. **完整性與錯誤**：回應是完整的當日盤口清單，還是部分更新？缺少比賽／玩法／選項時，如何區分尚未開盤、已關閉、無資料或 API 失敗？是否有穩定的賽事與市場 ID、版本，以及 401／403／429／額度用盡等錯誤格式？
7. **費用與用量**：API 文件目前列每月 NT$1,000、每日 300 次、請求間隔大於 5 秒，這是否仍適用？與一般網站分析會員是否為不同方案？是否允許本人手動點擊更新、伺服器背景完成匯入及後續定期更新？若同一次更新需查詢兩個日期，各算幾次？每日額度何時重置，是否有超額收費、合約期間或取消條件？
8. **測試樣本**：能否先提供移除 token、email 與帳務欄位的 NBA 樣本，包含未開賽全場盤、可單場／需串關、上半場、整數盤、封盤／停售及錯誤回應？如可試用，請提供允許的試用方式與限制；我不會以共用免費 key 做定期排程。

謝謝，收到授權範圍、目前報價與規格後，再確認申請方式。
